# Client asset-source verification

Updated: 2026-10-31. The current candidate source is `0.3.0-preview.3+8`; this document records its asset sources and verification methods. The detailed inventory dated 2026-10-02 applies to `0.2.0-preview.1+4`; historical counts and acceptance scopes retain their original dates. Every release must still check its source snapshot and final signed APK. Source records do not establish trademark availability.

2026-10-11 usage addition: task reminders in the then-current `0.2.0-preview.1+5` reuse `ic_focus_notification.xml`; no bitmap or drawable XML was added. Existing hashes for the notification icon, in-app branding, and adaptive foreground/monochrome images were rechecked and match the records below. This addition does not repeat the full asset inventory, final-APK license review, or device-display acceptance. The detailed inventory and symbol counts below retain their 2026-10-02 scope.

## Pactick application icon

The Android launcher icon and in-app brand mark have been replaced with the Pactick image generated by built-in imagegen for this round; Flutter's template launcher icon is no longer used. Generation referenced no third-party app icon and used no Flutter logo. Planning entries and an open folded ribbon form a focus window. The image retains subtle color gradations and is a bitmap asset.

The original transparent foreground is 1254 × 1254 RGBA. Original images, prompts, and generation-check records are under `output/pactick-app-icon/`; these work files are not packaged with the client or public source. Android/Flutter assets are derived by resizing and canvas conversion. Conversion adds no new drawn elements. Generation records document source and do not independently establish authorization or trademark clearance.

- `drawable/ic_launcher_foreground.png`: 432 × 432 transparent foreground for a 108 dp adaptive-icon canvas.
- `mipmap-anydpi-v26/`: foreground plus `launcher_background` forms Android 26+ adaptive icons. Standard and round launcher entries share the image. The original 2026-10-02 background was `#F4F5FF`; current `+5` uses `#F6F1E7`, with unchanged foreground bytes.
- `drawable/ic_launcher_monochrome.png`: a monochrome mask from pixels whose foreground alpha exceeds 32, supplied by `mipmap-anydpi-v33/` for Android 13+ themed icons.
- Five `mipmap-*/ic_launcher.png` and `ic_launcher_round.png` sizes: 48, 72, 96, 144, and 192 pixels for compatibility.
- `assets/branding/pactick_icon.png`: 512 × 512 in-app brand mark, declared in `pubspec.yaml` and included in the public-source exact allowlist.

The recognizable icon subject is inside Android's adaptive safe zone; the original image has extremely low-alpha specks around its edge. Resource dimensions and builds have been verified. Actual launcher masks, themed icons, and device display remain unverified.

## Focus notification icon

`client/android/app/src/main/res/drawable/ic_focus_notification.xml` uses official Google Material Design Icons `timer` at pinned upstream commit `737e3324305806514d7909874fa1818ae1808232`. The original [24px SVG](../third_party/metadata/material-timer/timer.svg), [source/hash record](../third_party/metadata/material-timer/SOURCE.json), and corresponding [Apache-2.0 text](../third_party/licenses/Asset-Material-timer-Apache-2.0.txt) are retained with public source.

The 2026-10-02 conversion writes SVG rectangles and paths as a white Android vector, preserving the 24 × 24 viewport and geometry and declaring source, license, and conversion date in XML comments. It is used for foreground timing notifications, guard notifications, and overlay reminders; task reminders added on 2026-10-11 reuse it. Current workspace SHA-256: `c00963d2e0bd8b9e453a4833f3aa19412683a1ad758b87afc25be07892c75c92`. After snapshot newline normalization, use its `SOURCE_MANIFEST.json`.

The current supplemental license asset includes the Google timer source, conversion notes, and full Apache-2.0 text; the client license page reads it. Source text and notices are prepared. Verify their consistency in the final APK with the [third-party checks](THIRD_PARTY_AUDIT.en.md#checks-after-every-signed-build). Actual notification rendering still requires phone checks.

The old focus-notification XML and historical circle/check `ic_launcher_foreground.xml` lack original-author and upstream records. Neither is used in the current client. Retaining historical files in maintenance directories does not mean they continue to ship in this candidate.

## Framework icons and fonts

The interface continues to use Flutter `Icons` and Material widgets, with `uses-material-design: true`. Since 2026-10-31, display headings use the bundled Noto Serif SC font, registered as `PactickDisplay` in Flutter. Body text, task titles, and controls retain sans-serif fonts and system fallback. Flutter supplies Material icon fonts at build time and may remove unused glyphs. The old `0.2.0-preview.1+3` APK contained only `MaterialIcons-Regular.otf` as a font asset, without Roboto, Roboto Condensed, or Microsoft YaHei. New builds must be rechecked.

`client/assets/fonts/NotoSerifSC.ttf` is the unmodified variable font from the official Google Fonts repository and contains Simplified Chinese and Latin glyphs. Its pinned upstream commit is [`8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5`](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notoserifsc). The file is 25,125,512 bytes and its SHA-256 is `050080d9255a86808f2945bffac582b31ef32bc36411ce29563b4961670c66f9`. It requires no runtime download and increases package size. The original [copyright and SIL Open Font License 1.1](../third_party/licenses/Font-NotoSerifSC-OFL-1.1.txt) are retained in the source and the in-app supplemental license page. This font keeps its independent license; Pactick's restrictions on its own code do not apply. Replacing or subsetting the font requires reviewing its license, provenance, and notices again. Source export permits only this reviewed font file, without adding other local fonts to the public scope.

The OFL text above has SHA-256 `5e0da210fb04058a8c0087985d2d456b931c2579811a49655721d3cf0c36b6d6`. `third_party/metadata/distribution-notices.json` pins the license text, supplemental notices, and source font hashes. TTF files are copied and exported as binary without newline normalization; `.gitattributes` marks them as binary too. Their sizes and hashes in source and archives must match this record.

After building the final APK from a fixed commit, run from the repository root:

```sh
python3 scripts/verify_supplemental_notices.py --root .
python3 scripts/verify_apk_notices.py client/build/app/outputs/flutter-apk/app-release.apk --root .
```

The second command requires Flutter on PATH; otherwise add `--engine-license /actualFlutterSDK/bin/cache/pkg/sky_engine/LICENSE`. When source declares or provides Noto Serif SC, it checks the exact bytes of `assets/flutter_assets/assets/fonts/NotoSerifSC.ttf` in the APK and the `FontManifest.json` mapping from `PactickDisplay` to that font's regular 400 weight. Missing or duplicate entries, wrong mappings, or mismatched hashes fail. Passing notice-text checks does not replace checking the font binary, and an old debug APK's result does not replace the final signed APK. The license entry and font rendering still require acceptance on actual devices.

The current SDK's [original Material icon font license](../third_party/licenses/Asset-Material-icons-fonts-Flutter-bundled-0-materialicons_license.txt) is Creative Commons Attribution 4.0 International (CC BY 4.0). Its font copyright reads `Copyright 2019 Google LLC. All Rights Reserved.` This differs from the independent SVG's Apache-2.0 license above. The upstream icon repository's current home-page description must not replace the text for the actual font version.

`client/assets/licenses/supplemental.json` preserves Google's attribution, pinned font-package source, full CC BY 4.0 text, and glyph-subsetting explanation and registers them in the client's `LicenseRegistry`. The font remains under its independent license; Pactick's Source Available commercial restrictions do not apply to this third-party font. Verify final-APK asset bytes and the license entry using the [third-party audit](THIRD_PARTY_AUDIT.en.md).

Isolated Flutter widget screenshot tests load local Microsoft YaHei and the SDK's MaterialIcons so Chinese and icons are readable. The YaHei font file is not declared as a product asset or copied to public source. Screenshot text is rendered pixels. Screenshot font appearance does not establish Android system-font or real TalkBack validation.
