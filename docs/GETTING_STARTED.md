# Pactick Android 入门指南

更新日期：2026-10-02。适用源码版本：`0.2.0-preview.1+5`。

Pactick 将任务、日历排期和专注记录保存在本机。首次使用无需登录，也无需准备服务器。新安装的工作区没有示例项目、任务或专注记录；空列表属于正常状态。

本文按当前实现说明操作。当前 Android 最低版本配置为 Android 8.0（API 26），首轮计划提供源码预览和 Android 预览版 APK。正式签名 APK、不同机型上的后台计时、权限变化、双设备同步和旧包迁移仍须完成[发布验收](RELEASE_AND_PROMOTION_PLAN.md)，不能据此承诺所有机型兼容。

## 下载安装与更新

项目入口已确定为 [Pactick 源码仓库](https://github.com/2354634715/Pactick)，APK 与版本说明使用该仓库的 [Releases 发布页](https://github.com/2354634715/Pactick/releases)。本次核对未能读取 GitHub 页面，尚未验证仓库、发布页或下载附件是否可访问，也没有已验收的正式签名 APK。

实际取得测试或发布包时，以对应发布说明为准。发布页应同时列出 APK、对应源码、SHA-256、签名证书指纹、支持范围和已知问题；页面不可访问或尚无附件时，不应把本文中的地址当作已有 APK 的证明。

1. 查看发布说明，确认版本、Android 要求和已知问题，下载与说明对应的 APK。
2. 核对 APK 的 SHA-256 与发布页公布的值。如果文件经过聊天软件或网盘转发，也应核对转发后的文件。使用 Windows 电脑时，可以在 PowerShell 中运行以下命令，将路径换成实际下载文件：

   ```powershell
   Get-FileHash -LiteralPath 'C:\实际下载目录\pactick.apk' -Algorithm SHA256
   ```

   哈希不一致时，不安装该文件，重新从已确认的发布入口下载。签名证书指纹用于核对发行者和后续更新签名，不能用文件哈希代替；需要工具核验时参见[发行流程](RELEASING.md)。
3. 在手机文件管理器或浏览器中打开 APK。系统要求允许此来源安装应用时，为当前用于打开 APK 的应用授权，再返回安装界面。各厂商的设置名称可能不同；Pixel 的操作见 [Google 安装说明](https://support.google.com/pixelphone/answer/7391672?hl=zh-Hans)。安装完成后，可关闭该来源的安装权限。
4. 打开 Pactick，按下一节创建第一项任务。安装所用的“允许来自此来源”权限属于浏览器或文件管理器，与 Pactick 的专注权限不同。

系统提示安全风险、开发者验证或安装限制时，先核对来源和完整提示，再向分发者反馈。不要仅凭文件名确认安装包身份。

更新前先导出本地备份。同包名更新需要兼容的签名和更高构建号；出现“签名冲突”“无法更新”或类似提示时，先核对旧包与新包的来源。不得通过卸载唯一持有数据的应用来尝试解决。安装失败也可检查剩余存储空间、下载是否完整，以及设备是否满足发布说明中的要求。

“设置 → 查看发布版本”只打开构建时配置的发布页。未配置时，该项不可点击，并提示查阅分发者的发布说明；当前客户端不在应用内下载安装更新。

## 完成第一次任务、排期和专注

手机上的主要页面为“今日、任务、日历、专注、统计”。设置可通过页面右上角标有“设置”的图标打开。横屏或较大窗口会调整导航和内容布局，页面名称相同。

新安装使用红、近黑与米白主题，亮暗模式默认跟随系统。在“设置 → 外观”中可选择亮暗模式或开启系统动态色；设备不提供动态色时使用默认主题。更新会保留已明确保存的外观选择；尚未保存动态色选择时，更新后使用默认主题。Android 深度守护的原生提醒按系统亮暗模式显示固定配色，不读取 Flutter 外观设置或系统动态色。

1. 打开“任务 → 新建任务”，填写“任务标题”。其他字段可以暂时留空；未选择项目的任务归入“收集箱”。需要分类时，在编辑表单中点“新建项目”，填写项目名称并创建，再选择该项目。点“保存任务”。
2. 需要时补充备注、优先级、截止日期、预计用时和标签。标签用逗号或顿号分隔。截止日期表示任务何时到期；它不会替代日历中的开始时间和计划时长。
3. 打开“日历 → 新建时段”，选择“关联任务”、日期、开始时间和计划时长，点“加入日历”。也可以从“未排期任务”中为任务安排时间。不关联任务时，必须填写日程标题。日历可切换日、周、月视图。
4. 打开“专注 → 开始”，选择一项未完成任务和目标时长。快捷时长为 25、45、60、90 分钟，也可通过滑块在 15–240 分钟内选择。第一次可选“灵活专注”，再点“开始专注”。没有未完成任务时，先创建任务。
5. 普通模式可点“暂停”或“继续”；暂停时间不计入实际专注用时。点“完成专注”后查看本次计划时长、实际专注和中断次数，再选择“暂不完成任务”“再专注一次”或“完成任务”。点“提前结束”时可填写原因，确认后仍保留本次实际用时。
6. 打开“专注 → 历史”查看记录；打开“统计”查看近 7 天或近 4 周的计划总时长、实际专注和完成任务数。计划时长来自日历时段，实际专注来自专注记录，两者可以不同。

保存出现错误时，表单会保留输入并显示错误；处理手机存储空间等问题后可再次保存。没有成功保存前，不应认为该修改已经写入本机或服务器。

目标时长结束后，应用继续记录专注时间，需点“完成专注”或“提前结束”保存本次记录。完成专注不必同时完成任务，也不会自动为下一次专注排期。

任务列表中的复选框用于标记完成或未完成；任务页可按收集箱、项目、标签和已完成状态筛选。点任务正文可查看完整标题、备注和标签，再选择编辑；完成操作后的提示中可点“撤销”。

## 普通模式、深度守护与权限

“灵活专注”是普通模式，允许暂停和提前结束。它不需要使用情况访问或悬浮窗权限。Android 专注计时通过前台服务运行；应用切到后台时按当前实现继续计时，实际机型上的强制停止、系统回收和重启恢复仍在验收范围内。

“深度守护”在专注期间识别前台应用：打开白名单外的应用时，在屏幕顶部显示返回专注的提醒。默认规则不允许暂停；离开次数超过 2 次后，后续离开计入中断。该模式提供提醒和记录，不阻止打开其他应用，当前“严格模式”尚不可用。

启用守护前，打开“专注 → 规则”，按收集箱或项目设置“应用白名单”。选中的应用可以在相应任务的守护过程中使用；白名单保存在本机当前工作区，不通过服务器同步，本地备份会包含该设置。换手机后需核对新机是否安装了这些应用。

| 权限或能力 | 当前用途 | 拒绝或关闭后的影响 |
| --- | --- | --- |
| 通知 | 显示专注前台计时服务的持续通知及守护通知 | 本地任务、计划和普通专注仍可使用；通知展示受 Android 系统限制 |
| 使用情况访问 | 深度守护读取前台应用切换，判断当前应用是否在白名单中 | 无法开始深度守护，普通模式仍可使用 |
| 显示在其他应用上层 | 在其他应用上方显示顶部守护提醒 | 无法开始深度守护，普通模式仍可使用 |
| 系统文件选择器 | 由用户选择备份保存位置或待恢复文件 | 取消选择时不导出或导入；不能读写所选文件时显示错误 |

使用情况访问和悬浮窗权限可在“设置 → 专注与权限”中点对应的“打开授权设置”，进入 Android 系统设置。已授权时，该操作显示为“检查系统设置”。授权后返回应用，确认状态已更新。专注中撤销权限后，相应守护能力会受限；悬浮窗无法显示时，实现会尝试改用通知提醒，通知权限也关闭时不能依赖该提醒。

Android 13 及以上需要通知运行时授权。在“设置 → 专注与权限 → 前台计时通知”中点“检查 / 申请”，应用会申请或检查通知权限，并显示本次调用结果。该接口不持续查询系统通知设置；也可以直接在手机系统的 Pactick 应用设置中管理通知。当前版本尚不支持任务与计划提醒、专注震动反馈或严格模式，设置页只说明这些限制，不提供对应开关。拒绝通知权限后，Android 不在普通通知栏显示相关通知；前台服务的显示规则见 [Android 通知权限说明](https://developer.android.com/develop/ui/compose/notifications/notification-permission?hl=zh-cn)。

## 备份、恢复、换手机和卸载

业务数据保存在 Pactick 的应用私有数据库中，普通文件管理器不会直接显示。当前 Android 配置关闭系统自动备份；换手机前应自行导出并保管备份。卸载应用或在系统设置中清除应用数据会删除本机数据库、工作区及设置，保留在应用外的导出文件不随本机数据库清除。

导出当前工作区：

1. 打开“设置 → 数据备份与工作区 → 导出本地备份”。
2. 在系统文件选择器中选保存位置，确认保存。出现“本地备份已保存”后，在所选位置确认文件存在。
3. 将文件另存到电脑或其他可信位置。切换工作区后，应分别导出需要保留的工作区；一次导出只包含当前工作区。

本地备份可以离线导出，包含当前工作区的业务数据、允许迁移的设置和未同步修改，不包含密码、登录令牌、服务器地址或同步游标。文件为未加密的 JSON，可能包含任务、备注、专注历史和应用白名单。存到第三方网盘时，该文件由所选存储服务处理；不要把真实备份上传到公开问题反馈或仓库。

从备份恢复或换手机：

1. 将备份复制到新手机能够通过文件选择器访问的位置。先结束新手机上正在进行的专注。
2. 打开“设置 → 从本地备份恢复”，选择文件。
3. 校验成功后，应用创建并打开新的本地工作区，原工作区保留。恢复不需要登录，不自动上传或连接原服务器。
4. 核对项目、任务、计划、历史记录和未同步内容。确认新手机数据正确并另存备份后，再决定是否清除旧手机数据。

当前只接受 `pactick-workspace` 格式、版本 `1`、UTF-8 编码、不超过 50 MiB 且不超过 100000 份文档的本地备份。文件损坏、格式不支持、超出限制、重复记录或引用无效时会报错；恢复写入失败会回滚，不覆盖原工作区，也不保留部分恢复结果。文件读写错误时检查文件、可用空间和访问权限；不要修改格式标识来尝试兼容未知旧文件。

备份中的尚未结束专注作为只读历史保留，恢复后不会接管源手机的计时，也不会结束源手机的会话。新工作区可以发起新的本机专注。备份中显示偏好和白名单的范围、详细迁移规则见[本地备份与工作区迁移](LOCAL_BACKUPS.md)。

“复制为本地工作区”会创建并打开离线副本，停止当前同步并保留原工作区。“打开保留的工作区”可重新查看初始本地工作区、恢复副本或其他账户在本机留下的数据，不连接服务器。恢复、复制和打开工作区前都需结束当前专注。

旧应用 `com.example.planfocus` 与当前 `com.example.pactick` 是不同 Android 应用。新应用不会自动读取旧应用的数据库、设置或登录信息，实际旧包的导出格式兼容性尚未确认。旧包迁移验证完成前，保留旧应用和原始备份；不要先卸载旧应用。

## 可选的自部署同步

仅在需要将数据同步到自己的服务器或其他设备时配置同步。维护者不提供公共同步服务。首轮以源码预览和 Android APK 为发行范围，真实 Linux 部署、恢复和公网 HTTPS/WSS 尚未完成验收，当前不推荐公网自部署。以下说明当前客户端的可选同步操作，不代表公网服务已经验证。测试服务器需由用户或可信管理员部署和维护，操作方法见[自部署指南](SELF_HOSTING.md)。

1. 先结束当前专注，导出需要保留的本地工作区。
2. 打开“设置 → 同步与设备 → 同步设置”，填写服务器 HTTPS 地址、邮箱和密码。服务器地址只接受站点地址，例如 `https://sync.example.com`；该示例不是可用服务。地址不得含接口路径、账号、查询参数或片段。
3. 默认不勾选“复制当前本地数据并上传”。首次在本机登录该服务器账户时，应用使用独立工作区，原工作区保留；服务器已有数据由同步获取。之后在同步工作区创建或修改的数据会同步到该服务器。
4. 只有明确需要迁移当前工作区时，才勾选“复制当前本地数据并上传”。此选项仅适用于本机首次使用该服务器账户的情况：复制当前工作区内容到新账户工作区，再将内容上传，原工作区保留。它不用于向本机已经存在的账户工作区追加或合并另一份数据。
5. 点“登录”，查看页面右上角的同步状态，或在“设置 → 同步与设备”中点“立即同步”。“同步完成”表示本轮更改已同步到服务器；仍有待同步或拒绝信息时，不能认为服务器已保存全部本机修改。

没有账户时可点“注册账户”，填写显示名称。注册需要服务器管理员临时开启注册；关闭注册后已有账户仍可登录。登录会将邮箱、密码等认证信息发送到指定服务器，并登记设备。同步会将工作区的业务记录和后续修改发送到该服务器，并将服务器变更保存到本机；服务器管理员负责服务器数据、备份与凭据管理。选择服务器前，应确认由谁维护以及其数据处理方式。

连接失败时核对地址、网络、证书和账户信息。登录失效时重新登录；服务暂不可用或断网时，本机已保存的数据仍可编辑和导出，待同步内容保留。自动重试仍失败时，可打开同步状态面板查看具体错误，处理后点“立即同步”。同步被拒绝或出现版本不兼容提示时，保留本地备份并联系管理员或分发者，不通过清除应用数据处理。

同一账户的其他设备可以查看已同步的专注记录，但只能在发起设备暂停或结束该会话。其他设备存在活跃专注时，本机需等待发起设备结束并同步后再开始。

### 切换服务器、退出和删除

切换前结束专注并导出当前本地备份。在“同步设置”中填写另一台服务器地址并登录，应用按服务器和账户使用独立工作区，不复用另一台服务器的数据、凭据或同步游标。需要复制到新服务器时，应在该账户首次使用时单独选择复制上传。旧工作区可通过“打开保留的工作区”离线查看；旧服务器是否撤销登录，应在原服务器确认。

“退出登录”停止同步并保留本机工作区，任务、计划和历史仍可编辑和导出。退出不会删除服务器账户或业务数据。网络不可用时，应用可能提示无法确认服务器已撤销此次登录；本机退出结果与服务器撤销结果应分别查看。若提示无法确认本机登录信息已清除，先保存备份，再处理手机端凭据，避免用清除应用数据丢失唯一副本。

登录后可使用“导出服务器账户数据”，需要联网且不包含本机尚未同步的修改。它与“导出本地备份”的格式和用途不同，不能直接作为当前本地恢复入口的文件；停用服务器前应同时导出本地备份。

“删除服务器账户”需要当前密码和输入 `DELETE` 确认，会永久删除指定服务器上的当前账户及其业务数据，保留本机副本。此操作不可撤销，执行前应导出并核对所需数据。它不删除其他服务器上的账户，也不替服务器管理员清理既有备份或日志；这些内容的保留与清除需联系该服务器管理员。删除失败时查看错误并核对账户状态，不把失败提示当作已完成删除。

“设置 → 同步与设备”中的“撤销设备登录”使所选其他设备的服务器登录失效，不会远程删除其本机数据。

## 常见问题与反馈

| 问题 | 处理方式 |
| --- | --- |
| 首次打开没有任务或统计 | 新工作区为空；创建任务、安排日历时段并结束一次专注后查看对应页面 |
| 找不到刚创建的任务 | 检查任务页的收集箱、项目、标签和已完成筛选，以及当前打开的工作区；“今日”列表还与所选日期有关 |
| 无法开始专注 | 先创建未完成任务；守护模式需两项专注权限；其他设备的活跃会话需在发起设备结束并同步 |
| 无法打开本地工作区 | 点“重试”；仍失败时记录提示并反馈，保留已有备份，不先清除应用数据 |
| 日历到时间没有提醒 | 当前版本尚不支持任务和计划提醒，不会按日历时段调度提醒通知 |
| 专注通知没有出现 | 检查 Android 的应用通知权限和渠道设置；通知展示及后台计时的机型兼容性仍须验收 |
| 导出后文件找不到 | 检查系统文件选择器中选定的位置，并确认出现保存成功提示；取消选择不算导出成功 |
| 登录后原有任务不见了 | 新服务器账户使用独立工作区；在“打开保留的工作区”中查看原数据，无需重新上传 |
