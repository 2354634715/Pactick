# Pactick Android 入门指南

[English](GETTING_STARTED.en.md)

更新日期：2026-10-31。适用版本：`0.3.0-preview.3+8`。本指南说明 Android 客户端的操作；安装件、设备验证范围和已知问题以对应版本的发布说明为准。

Pactick 将任务、日历计划和专注记录保存在本机。首次使用无需登录或准备服务器，新工作区没有示例任务。账户同步、系统日历连接和专注桌面按需启用；私密任务箱使用独立密码，内容不参与账户同步。

## 安装与覆盖更新

Android 最低要求为 Android 8.0（API 26）。从 [Pactick Releases](https://github.com/2354634715/Pactick/releases) 选择对应版本，先阅读支持范围和已知问题，再下载 APK。不要用文件名判断安装包来源。

1. 核对发布页公布的 APK SHA-256。在 Windows 下载目录打开 PowerShell，可运行 `Get-FileHash -LiteralPath '.\pactick.apk' -Algorithm SHA256`，文件名换成实际下载名称。哈希不一致时重新下载，不安装该文件。签名证书用于核对发行者和覆盖更新，不能用文件哈希替代；核验方法见[发行流程](RELEASING.md)。
2. 在手机文件管理器或浏览器中打开 APK。系统要求“允许来自此来源”时，授权当前打开文件的应用，再继续安装；这与 Pactick 的通知或专注权限分别管理。
3. 打开 Pactick。覆盖更新后核对已有任务、计划、历史和未同步修改。

更新前先导出所需工作区的本地备份；有私密内容时同时保留密文与其导出时的密码。同包名覆盖更新需要兼容的签名和更高构建号。出现签名冲突或无法更新时，核对新旧包来源、存储空间和系统版本，不通过卸载唯一数据副本处理安装问题。

“设置 → 关于 → 查看发布版本”通过系统浏览器打开构建时配置的 HTTPS 发布页，不在应用内自动下载安装。未配置发布页时入口禁用；地址或浏览器失败时显示提示。旧包 `com.example.planfocus` 与当前 `com.example.pactick` 是独立应用，不自动迁移数据；旧包导出兼容性确认前保留原应用和备份。

## 页面、语言与外观

Android 手机底部导航依次为“专注、今日、任务、日历、统计”，默认打开“今日”。较宽窗口使用侧边导航；设置从页面右上角的齿轮打开。

在“设置 → 外观 → 语言”选择“跟随系统”“简体中文”或“English”。默认跟随系统：中文系统变体使用简体中文，其他系统语言使用英语。选择保存在本机，不改写任务、项目、自定义规则或日历名称。界面、日期和应用通知使用所选语言，详见[语言支持](LOCALIZATION.md)。

亮暗模式默认跟随系统，动态取色默认关闭；可在同一区域修改。固定主题使用品牌红与浅深色表面，页面标题使用随包分发的宋体，正文和操作保留无衬线字体。开启动态取色但系统未提供颜色时，仍使用固定主题。更新保留已经保存的外观选择；原生守护提示和专注桌面按系统亮暗模式显示固定配色。

## 新建任务与安排时间

1. 打开“任务 → 新建任务”，填写任务标题，点“保存任务”。未选择项目时归入“收集箱”；需要分类时可先在编辑器中新建项目。
2. 按需补充备注、优先级、截止日期与时间、预计用时和标签。标签用逗号或顿号分隔。只选截止日期而不改时间时，截止时间为当天 `00:00`；需要日间提醒时同时选择时间。
3. 打开“日历 → 新建时段”，选择关联任务、日期、开始时间与计划时长，点“加入日历”。也可从“未排期任务”或任务详情安排时间。不关联任务时必须填写日程标题，同一任务可有多个时段。
4. 修改已有安排时，在日历打开该记录，点“编辑计划时段”；也可从任务详情的“计划时段”进入。修改后点“保存修改”，沿用原计划，不创建副本。点“删除时段”并确认，仅删除该计划，任务和历史专注保留。

任务截止时间、日历计划与实际专注分别保存。修改计划不会改变任务截止时间或重算历史专注。计划时长以分钟输入，允许小数，至少 1 秒；计划按设备本地日期和时间输入，设备时区变化后显示时间可能改变。系统日历交换另有跨度限制，见下文。

任务列表默认按“紧急 → 高 → 中 → 低 → 无”排列，同优先级按原有顺序；“今日”保留当天排期和手动顺序。任务页可按收集箱、项目、标签、已完成状态筛选并搜索。点正文查看完整内容，再选择编辑；复选框切换完成状态，完成提示可撤销。普通任务删除与独立标签管理当前没有完整界面入口。

普通编辑表单未保存时，关闭会确认是否放弃；保存失败保留输入供重试。编辑期间切换工作区后，关闭原编辑器并在当前工作区重新打开。私密编辑器的锁定规则见“私密任务箱”。

## 开始专注与关联任务

1. 打开“专注 → 开始”，选择任务，或保留“自由专注（暂不关联任务）”。没有任务也可直接开始。
2. 选择目标时长与规则。准备页默认 45 分钟，快捷值为 25、45、60、90 分钟，滑块范围为 15–240 分钟；从任务快捷入口开始时使用该任务预计用时，没有预计用时时为 25 分钟。
3. 选择“灵活专注”并点“开始专注”。该模式允许暂停与继续，暂停时间不计入实际专注。守护及严格模式的额外条件见下一节。
4. 目标到达后应用继续记录；点“完成专注”或“提前结束”保存。结束专注不会自动完成任务，也不会自动安排下一次时段。完成后的复盘可另选完成任务或再专注一次。
5. 自由专注结束后，可在复盘关联现有任务或新建任务，也可暂不关联，之后从“专注 → 历史”打开记录再关联。关联后，已记录时长计入所选任务，起止、暂停和实际用时不变，任务不会自动完成。

只有尚未关联任务的已结束记录可首次关联；关联后不能改绑或清除。同步工作区中只能在发起设备关联，其他设备的记录只读；本地备份恢复的终态历史可关联，不因此接管源设备计时。正在运行的专注须先结束。

需要同步任务关联时，先将自部署服务端升级到 preview.3 源码。旧服务端（包括仍单独提供下载的 preview.1 预编译包）会拒绝终态记录的补关联请求。本版提供更新后的服务端源码，不附新的服务端二进制；操作见[服务端升级](SELF_HOSTING.md#4-升级)。若旧端拒绝同步，保留本机更改，升级后再检查同步状态。

“统计”展示近 7 天或近 4 周的计划、实际专注和完成任务数；自由专注也保留实际用时。计划来自日历时段，实际来自已保存的专注记录，两者可以不同。私密箱记录不进入普通统计。

## 守护、严格模式与震动

| 默认规则 | 暂停 | 目标前完成 | 提前结束 | 离开白名单应用 |
| --- | --- | --- | --- | --- |
| 灵活专注 | 允许 | 允许 | 确认后保存 | 不监测 |
| 深度守护 | 不允许 | 允许 | 确认页等待 10 秒 | 显示返回提醒，超过 2 次后的离开计为中断 |
| 严格专注 | 不允许 | 不允许 | 等待至少 30 秒并填写原因 | 显示返回提醒，每次离开计为中断 |

使用守护或严格模式前，在“专注 → 规则”设置项目或收集箱的应用白名单；自由专注使用收集箱白名单。随后在“设置 → 专注与权限”授予“使用情况访问”和“显示在其他应用上层”，返回应用核对状态。白名单保存在当前本机工作区，不上传服务器；本地备份会携带，换手机后须核对应用是否仍已安装。

提前结束会保存实际时间与原因，不完成任务。取消确认后再次进入须重新等待；重启进程也须重新确认。两种守护模式提供提醒和记录，不提供系统应用锁、卸载限制或强行停止保护。权限撤销、系统回收及厂商后台策略可能中断监测。

“设置 → 专注与权限 → 专注震动反馈”默认开启，本机保存。开始、暂停、继续、结束、目标到时和守护提示可触发震动，是否实际反馈还取决于规则、系统设置与硬件。关闭后不主动触发震动；没有硬件或平台调用失败不会撤销已保存记录。平台计时服务失败时查看设置或专注页的重试提示。详细规则见[专注模式](FOCUS_MODES.md)。

## 使用专注桌面

专注桌面默认关闭。在“设置 → 专注与权限 → 专注桌面”开启后，新开始或继续本机专注会自动打开；仅打开开关、回到前台或恢复计时服务不会跳转。

桌面显示剩余时间、状态、Pactick、可启动的系统应用和当前白名单应用。点图标打开应用；点返回客户端按钮或 Pactick 图标回到专注页。普通专注与私密专注的活跃区域也提供“打开专注桌面”；自动打开失败时可重试，已保存的专注继续计时。目标到达不会替普通专注自动结束。

开关仅保存在当前设备，不同步、不随备份迁移。普通模式使用桌面无需额外授予守护权限；守护和严格模式仍需要上述权限。桌面开启期间，守护也允许系统应用；关闭后恢复原白名单规则。它不替换 Android 默认桌面，Home、最近任务和其他系统入口仍可离开。私密专注只显示通用名称，使用所属工作区的收集箱白名单，打开桌面不会解锁私密箱。

## 管理任务通知

“设置 → 任务提醒”有两个独立且默认开启的本机开关：

| 开关 | 何时提醒 | 显示内容 |
| --- | --- | --- |
| 任务温馨提醒 | 当前工作区有未完成任务时；数量变化更新同一条通知 | 静默待办数量，不含任务正文 |
| 截止与计划开始提醒 | 未完成任务到达截止时间，或待执行计划到达开始时间 | 一条可清除的通用通知，不含任务名称 |

独立日程也可产生开始提醒。任务完成、取消或删除后不再安排其截止和关联计划提醒；计划完成、取消或删除后不再安排其开始提醒。两个开关跨工作区保留，但不随同步、备份或复制迁移。

Android 13 及以上需要通知运行时权限；应用通知与各通知分类也须允许。自动权限申请拒绝后不会随数据变化反复弹窗，可在此页点“检查 / 申请通知权限”，并分别检查系统提醒设置和定时提醒分类。应用共用通知权限，任务数量、定时提醒和前台计时使用各自的分类。拒绝通知不阻止本地保存或普通计时。

定时提醒使用非精确闹钟，节电和厂商策略可能延迟，不适用于必须准点的闹钟。新载入的过期事件不补发；事件到时若通知权限或分类关闭，之后授权也不补发。重启和覆盖更新后按最近本机快照恢复；系统强行停止后须重新打开应用。提醒不自行连接服务器，其他设备更改须先同步到本机。详细限制见[计划与提醒](TASK_SCHEDULING_AND_REMINDERS.md)。

## 连接 Android 系统日历

连接默认关闭，不要求 Pactick 账户。启用后，系统日程会成为当前工作区的普通计划，普通计划也可写入所选可写日历；该工作区已启用账户同步时，导入计划可能上传到 Pactick 服务器。系统日历所属账户也可能把日程同步到其服务商。私密箱不参与交换。

1. 在 Android 日历应用中准备已有日历，再打开“设置 → 系统日历 → 选择系统日历”，按提示授予读取权限。
2. 选择日历，阅读数据流说明并点“启用同步”。写入或删除另需 Android 写入权限及日历/事件可写权限；仅获读取权限时可使用只读连接。
3. 首次启用立即同步。默认范围是过去 30 天至未来 180 天，未来可改为 30、90、180、365 天。应用在前台合并变更后交换，也可点“立即同步日历”。
4. 两侧同时修改或任一侧删除时，在冲突列表选择“保留客户端版本”或“保留系统版本”，先阅读将修改或删除哪一侧。另一侧缺失时，选择保留它的缺失状态可能删除仍存在的副本；关闭页面不自动裁决。
5. 不再使用时关闭“系统日历同步”。已导入的计划与已经写出的系统事件保留；换日历也不自动删除旧日历副本。

只交换普通计划的标题、起止和时区，不导出任务截止、专注记录或私密内容，不改系统描述、地点、提醒及与会者。客户端可表示的计划跨度不超过 7 天；不支持的事件保留系统原值并跳过或列为冲突。重复事件、全天、时区及读取上限见[系统日历同步](SYSTEM_CALENDAR.md)。

应用退出前台后不保证即时交换；提供程序读写成功不表示其服务商网络同步已完成。连接按本机工作区保存，不随备份或复制迁移，换手机后重新配置。同一 Pactick 账户在多台设备连接同一系统日历可能重复，建议只在一台设备启用。权限被撤销或读取失败时停止交换，保留已有计划；处理权限或日历状态后重试。

## 私密任务箱与独立密文备份

1. 点任务页右上角的锁图标，或打开“设置 → 数据备份与工作区 → 私密任务箱”。首次输入并确认 8–1024 个字符的独立密码；该密码与同步账户无关。
2. 解锁后新建私密任务，可设置分类、标签、截止、计划和专注。私密计划时间格式为 `yyyy-MM-dd HH:mm`；在私密箱查看或修改，不在普通日历展示，也不产生截止或计划开始提醒。
3. 私密专注必须选择箱内任务，默认 25 分钟，可设置 1–1440 分钟；当前不提供暂停、守护或严格模式。同一时刻只允许一个普通或私密专注。锁定后通用计时继续；查看正文或提前结束须解锁原工作区。
4. 点“密文备份 → 保存私密密文备份文件”，通过系统文件选择器保存，并在所选位置确认文件存在。文件选择器会使私密箱锁定，不表示导出失败；以保存结果为准。
5. 恢复时在私密箱锁定页选“恢复私密密文备份”，或在已解锁的“密文备份”页选“打开私密密文备份文件”。选择文件，输入导出时的密码，点“验证并恢复到新的本地工作区”。无需先为新设备设置另一套密码。验证成功后创建新工作区并保留原工作区；再从“设置 → 数据备份与工作区 → 打开保留的工作区”打开恢复副本并解锁。

私密内容不进入普通列表、搜索、统计、系统日历或账户同步；通知和桌面只显示“私密任务”等通用名称。应用离开前台、离开私密页、切换工作区或手动锁定时清除解锁状态及未保存私密输入。Android 进入私密页前启用系统截图保护，无法启用时不打开页面。

独立密文备份最多 50 MiB，包含解密所需参数但不含密码或明文密钥。密码错误或文件损坏时保持原数据，不创建恢复工作区；多次失败会增加等待。密码遗失后无法绕过恢复；修改密码须验证旧密码，旧备份仍使用其导出时的密码。

普通任务的“更多 → 转入私密任务箱”仅适用于原始本地工作区中从未尝试同步、没有系统日历曝光且满足关联约束的记录。关闭同步或解绑日历不清除历史，不回收旧备份和外部副本。私密任务“移出私密箱”会在确认后写回普通存储，在同步工作区可能上传服务器。操作限制与删除影响见[私密任务箱](PRIVATE_TASK_VAULT.md)。

## 完整备份、换手机与卸载

Android 系统自动备份已关闭。卸载应用或清除应用数据会删除本机工作区、设置和私密密文；应用外已导出的文件另行保管。

1. 在“设置 → 数据备份与工作区 → 导出本地备份”保存当前工作区。出现保存成功后确认文件存在，另存到可信位置；多个工作区分别导出。
2. 在新手机先结束本机专注，再选择“从本地备份恢复”并选文件。校验成功后创建并打开新的离线工作区，原工作区保留，不自动登录或上传。
3. 核对任务、计划、历史和未同步修改。有私密箱时用原密码解锁并确认；确认可恢复并另存备份后，再决定是否清除旧机。

完整备份使用 `pactick-workspace` v2，仍可恢复旧版 v1；接受 UTF-8、最多 50 MiB、最多 100000 份普通文档。普通任务、备注、历史与白名单为明文；私密部分保持密文，完整恢复只校验其格式，认证在解锁时执行。需要创建工作区前验证私密内容时，使用独立私密备份入口。真实备份不得公开上传到问题反馈。

备份不含账户密码、登录令牌、服务器地址、同步游标或本机计时控制权。恢复中的活跃记录不会接管源设备计时；私密活跃记录在首次解锁时标为中断。系统日历连接、提醒开关、语言和专注桌面设置需按目标设备配置。格式、重复或引用错误时不恢复；本地恢复写入失败会回滚，保留原工作区。详情见[本地备份](LOCAL_BACKUPS.md)。

“复制为本地工作区”创建并打开离线副本，停止当前同步并保留原工作区；“打开保留的工作区”用于离线查看旧工作区。恢复、复制或切换前须结束本机专注；单纯导出本地备份无需结束普通专注。

## 可选账户同步、退出与删除

维护者不提供公共同步服务。需要多设备交换普通数据时，先按[自部署指南](SELF_HOSTING.md)准备由自己或可信管理员维护的 HTTPS 服务器；实际部署、恢复和公网兼容性以相应版本验收为准。

1. 结束本机专注并导出当前工作区备份。
2. 打开“设置 → 同步与设备 → 同步设置”，输入服务器站点 HTTPS 地址、邮箱和密码。地址例如 `https://sync.example.com`，不含接口路径、凭据、查询或片段；该示例不是可用服务。
3. 默认不选择“复制当前本地数据并上传”。首次连接该服务器账户时打开独立工作区，保留原数据；服务器已有普通数据通过同步获取。仅确需迁移，且该账户在本机尚无工作区时才选择复制上传；这不是向已有工作区追加合并的入口。
4. 登录后查看同步状态；需要时点“立即同步”。未同步数量或拒绝仍存在时，不能认为服务器已保存全部修改。注册是否可用由管理员控制，关闭注册不影响已有账户登录。

本机数据、凭据、设备登记和同步状态按服务器与账户隔离。换服务器前保存备份，旧工作区可离线打开。断网仍可编辑和导出，待发送修改保留；连接失败检查地址、网络、证书，认证失效后重新登录。其他设备的活跃专注只读，需由发起设备结束并同步后才能开始新的普通专注。

“退出登录”停止同步并保留本机数据，不删除服务器账户；无法确认远端撤销时，单独查看提示。“导出服务器账户数据”需要联网，不含未上传修改，格式不能直接用于本地恢复。删除服务器账户需当前密码和 `DELETE`，会永久删除指定服务器的当前账户数据并保留本机副本；不删除其他服务器账户，也不清理管理员备份或日志。“撤销设备登录”使该设备登录失效，不远程清除其本机数据。

## 故障处理与反馈

| 情况 | 操作 |
| --- | --- |
| 列表为空或任务不见了 | 检查工作区、项目/标签/完成筛选与所选日期；新安装为空属于正常状态 |
| 保存失败 | 保留表单，检查错误、存储空间或网络后重试；私密箱锁定会清除其未保存输入 |
| 通知未显示或延迟 | 核对开关、应用通知权限和对应分类；强行停止后重新打开，非精确闹钟可能延迟 |
| 守护或严格模式无法开始 | 核对使用情况访问、悬浮窗及当前会话；普通模式无需这两项权限 |
| 桌面未打开 | 保留正在记录的专注，使用“重试打开专注桌面”，不要重复开始 |
| 系统日历没有变化 | 确认已启用、当前工作区/日历/窗口正确，应用在前台，并查看权限或冲突提示 |
| 私密密码或备份失败 | 保留原密文和文件，等重试时间后核对导出时密码；无绕过密码的恢复方式 |
| 本地工作区打不开 | 使用“重试”，记录完整提示，不先卸载或清除唯一副本 |

一般问题在 [Issues](https://github.com/2354634715/Pactick/issues) 提交版本、机型、Android 版本、步骤、预期与实际结果。使用演示数据或遮挡私人信息，不公开上传真实备份、数据库、密码和令牌；安全问题按[安全报告说明](../SECURITY.md)私下提交。

“设置 → 关于 Pactick”可查看应用及第三方许可证。项目使用 Source Available 许可，分发范围见[许可 FAQ](LICENSE_FAQ.md)。
