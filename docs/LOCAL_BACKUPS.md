# 本地备份与工作区迁移

备份导出和导入均可离线执行。导入会创建新的本地工作区并保留原工作区，不登录服务器或自动上传数据。

## 备份内容

备份是 UTF-8 JSON 文件，格式标识为 `pactick-workspace`，当前版本为 `1`，最大支持 50 MiB。文件包含：

- 项目、任务、周期规则、标签、计划、每日条目、专注策略、专注记录、中断与提醒。
- 本机已保存的最新正文、删除标记，以及尚未同步或被服务器拒绝的修改。
- 主题、动态配色、通知开关和专注应用白名单等允许迁移的设置。

备份不包含登录密码、访问令牌、刷新令牌、服务器地址、同步游标或原服务器的同步操作 ID。导入后，工作区不保留与原服务器的连接或同步凭据。

备份不包含本机活跃专注的控制标记。恢复或复制后的本地工作区保留原会话正文；尚未结束的原会话作为只读记录显示，不启动本机计时服务，也不允许本机改变原会话状态。副本可以开始新的本机专注。恢复副本不会结束源设备的专注。

文件没有加密，包含任务、笔记及本地设置。应保存在可信位置；不得将真实备份提交到公开仓库或附在问题反馈中。

## 导入与恢复

导入前，恢复服务检查格式版本、字段类型、记录 ID、重复记录和数据引用。目标必须是新工作区。所有写入使用一个 SQLite 事务：任何一步失败都会回滚，不保留部分写入的工作区，也不覆盖原数据。

恢复使用备份文件中的最新文档状态。旧同步操作仅作为备份中的未同步修改记录保留，不发送到其他服务器。已删除内容保留删除标记；常规列表不显示这些内容。

恢复后的工作区不带同步会话或同步队列。连接服务器和上传数据需在同步设置中单独选择。全局显示偏好也保存在恢复工作区的设置中；导入本身不会覆盖当前应用的全局偏好。

## 工作区复制与版本迁移

“复制为本地工作区”保留源工作区，生成一个新的离线副本，用于停用服务或更换服务器前保留数据。副本可以再次导出。

旧客户端仅用用户 ID 区分云端工作区。升级到服务器命名空间时，迁移前必须确认原登录会话与目标命名空间属于同一台服务器。该迁移复制业务记录、待同步队列和原服务器游标，同时保留旧工作区；目标已存在时不会合并或覆盖。

复制到另一台服务器时重新创建同步操作 ID，并重置文档版本与同步游标。历史记录引用的已删除父记录会先在目标建立，再保留其删除状态。周期任务先建立任务和周期规则，再附加规则引用。存在无法转换为新服务器有效引用的内容时，复制操作在事务开始前报错，不修改原工作区。

## 开发接口与验证

`WorkspaceBackupService` 提供：

```dart
final backups = WorkspaceBackupService(documentStore);
final json = await backups.exportJson(selectedAccountId);
final restoredAccountId = await backups.restoreJson(json);
final copiedAccountId = await backups.copyToLocal(selectedAccountId);
```

`DocumentStore.copyWorkspace(sourceId, newTargetId, enqueueForSync: true)` 用于用户明确选择向新服务器上传数据的操作。它不会连接网络。`migrateLegacyAccount(legacyUserId, namespacedId)` 仅用于已验证服务器一致性的升级迁移。

`client/test/workspace_backup_test.dart` 对内存存储和真实 SQLite 执行相同的备份、恢复、跨服务器操作生成、删除引用、周期引用和输入校验场景，并使用 SQLite 触发器注入中途失败，验证事务完整回滚。
