# 项目功能与验证状态

[English](PROJECT_STATUS.en.md)

核对日期：2026-10-31。适用版本：`0.3.0-preview.3+8`。本文描述本版整合源码，不用其他工作树、旧安装件或历史日志代替最终候选的验证。安装与操作见[入门指南](GETTING_STARTED.md)。

## 当前功能与默认值

| 功能 | 当前行为与默认值 | 主要限制 |
| --- | --- | --- |
| 语言与界面 | 默认跟随系统，可选简体中文或英语；手机底栏为专注、今日、任务、日历、统计，默认今日 | 用户输入名称不翻译；宽屏 Rail/Drawer 保留原顺序 |
| 任务与计划 | 任务优先级排序、创建编辑与完成；计划可新增、编辑和删除 | 删除计划保留任务与专注历史；没有普通任务删除、独立标签管理或重复规则编辑的完整界面 |
| 自由专注 | 可不选任务开始，结束后从复盘或历史首次关联已有或新任务 | 仅首次关联，不可改绑或清除；计时和暂停不变；同步记录由发起设备关联 |
| 普通、守护与严格 | 目标到达后继续计时；严格模式禁止暂停及目标前完成，紧急结束至少等待 30 秒并填写原因 | 守护依赖系统权限；不是系统应用锁，不能防止强行停止 |
| 反馈与提醒 | 任务数量通知、截止/开始提醒及专注震动默认开启，开关保存在本机 | 非精确闹钟可能延迟；私密记录不参与普通任务提醒 |
| 专注桌面 | 默认关闭，开启后新开始或继续专注可自动进入，亦可手动打开 | 只展示 Pactick、系统应用和当前白名单；不替换系统桌面、不隔离应用、不拦 Home/最近任务 |
| 系统日历 | 默认关闭，按工作区选择连接，过去 30 天与未来 180 天；可只读或双向更新普通计划标题、起止与时区 | 权限按需申请；冲突和单侧删除需人工处理；私密箱、任务截止和专注不参加，不保证后台即时或服务商联网同步 |
| 私密任务箱 | 独立工作区密码、认证加密、本机计划/普通模式专注与密文备份 | 不进入普通同步、搜索或统计；失去密码无法恢复；已外发的普通明文不会因转入而删除 |
| 工作区备份 | 版本 2，仍接受版本 1，最大 50 MiB；事务恢复到新工作区 | 普通内容仍为明文；私密部分为密文；不携带凭据、计时控制权、日历绑定或桌面开关 |
| 服务端与官网 | Go 认证/同步/管理工具；中英文静态官网源码与本机预览 | 终态首次关联要求本版服务端；本版不新增服务器预编译附件，也不部署官网 |

完整规则分别见[专注模式](FOCUS_MODES.md)、[系统日历](SYSTEM_CALENDAR.md)、[私密任务箱](PRIVATE_TASK_VAULT.md)及[备份](LOCAL_BACKUPS.md)。

## 兼容性与验证范围

终态专注的首次任务关联是本版新增的服务端例外；旧服务端仍会拒绝该请求。自部署者应按本版源码升级，保留数据库和原工作区备份，不移动历史迁移或复用其他服务器游标。接口字段与设备限制见[实体契约](ENTITY_SCHEMAS.md)。

公开源码归档、APK、来源提交、校验和和已执行检查以本版 Release 说明为准。构建、签名、组件测试、真实数据库检查和设备验收分别记录；没有设置 `PACTICK_TEST_DATABASE_URL` 而跳过的测试不能记为数据库通过。

旧版的真机结果不自动适用于本版的专注桌面、系统日历、语言、自由专注及其他合并改动。权限、厂商后台、锁屏与重启、外部应用返回、TalkBack、双设备和公网部署仍须按实际环境验收。后续完成条件见[路线图](../PROJECT_PLAN.md)。
