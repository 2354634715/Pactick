# Pactick Android GUI 改造方案

日期：2026-10-02。适用客户端：`0.2.0-preview.1+3`。

本文记录第一阶段检查与已确认设计。第二阶段已按此方案实施，实际变化、验证结果和未验证事项见 [GUI 实施记录](ANDROID_GUI_IMPLEMENTATION.md)。第 1 节的当前行为与源码行号对应改造前的检查版本，不表示改造后仍存在相同问题。

第一阶段只新增方案和独立预览文件，没有修改 `client` 产品代码。设计预览中的示例数据只存在于 HTML 内存中，不连接数据库、服务器或正式工作区；预览配色表达语义关系，最终色值由 Flutter `ColorScheme` 生成。第二阶段的实际 Flutter 截图使用隔离测试数据，记录与预览分别保存；README 未改写。

## 2. 信息架构、导航与流程

主导航仍为：今日、任务、日历、专注、统计。设置单独打开，页面显示返回按钮和“设置”标题，不伪装为第六个主导航目的地。页面设置入口使用齿轮，账户信息放在同步设置，避免以账户图标暗示必须登录。

五个主页面保持稳定身份；主页面切换、设置往返及窗口变化保留筛选、日期、搜索、选中任务和合理的滚动位置。设置 route 共享现有 scope，不复制 controller。编辑器在已打开后不因断点变化销毁或重新创建草稿。

| 流程 | 页面与操作 | 完成或失败后的结果 |
| --- | --- | --- |
| 收集任务 | 今日/任务“新建任务” → 任务编辑器 → 保存 | 写入成功后关闭，列表显示真实任务；失败留在表单 |
| 安排时间 | 日历“新建时段”或未排期任务“安排时间” → 计划编辑器 | 截止时间不改；计划写入成功后返回所选日期议程 |
| 执行任务 | 今日/任务快捷专注，或专注页选任务和规则 | 快捷专注沿用现有预计时长或 25 分钟默认；专注准备页仍默认 45 分钟 |
| 返回活跃专注 | 其他页面底部共享 dock → 专注页 | 本机会话继续计时；导航不新建会话 |
| 完成专注 | 本机活跃页“完成专注” → 保存终态 → 复盘 | 完成专注不会自动完成任务；用户再选择完成任务、再专注或返回 |
| 可选同步 | 设置 → 同步设置 → 服务器和登录/注册 → 上传选择 → 连接 | 默认不复制本地数据；连接失败保留输入，本地使用继续 |
| 数据恢复 | 设置 → 选择备份 → 校验 → 恢复到新本地工作区 | 原工作区保留；失败不留下部分恢复数据，不自动上传 |

全局同步状态由图标、简短文字与详情面板表达：仅本地、已同步、待同步、同步中、离线可用、同步异常。仅本地不视为故障；需要处理的同步错误才显示行内提示。顶部小空间优先保留可访问的状态按钮，完整服务器、账户、时间和错误原因进入详情面板。

## 3. 共享布局与组件规则

### 3.1 网格、对齐和留白

页面边距按实际内容区宽度选择：小于 600 为 16，600–839 为 24，840 及以上为 32。导航所占空间先扣除。边距属于页面，不由各卡片重复增加。

页面标题、区域标题、搜索/表单标签与列表内容起始边建立两条可识别的对齐线：页面外缘线和任务正文线。任务行完成控件占 48，控件与正文间隔 8，因此任务正文相对于列表起始边缩进 56；分组标题可选择正文线，须在同一列表中一致。标题、正文、更多按钮不能各自引入无关内边距。

| 关系 | 间距 | 目的 |
| --- | --- | --- |
| 图标与短标签、紧邻状态 | 4–8 | 表达同一信息 |
| 标题与辅助信息 | 4 | 保持同一任务的读取关系 |
| 同组字段或控件 | 12–16 | 区分控件，避免误触 |
| 区域标题与区域内容 | 12 | 保持标题归属 |
| 两个业务分组 | 32 | 使分组比组内更明显 |
| 双栏间距 | 24 | 区分列表/详情或日历/未排期 |
| 页面主要内容结束 | 24 加真实 FAB/底栏占用 | 最后一项可滚到操作不遮挡的位置 |

单列内容最大宽 720，连续说明正文最大宽 680，登录表单最大宽 560，编辑器最大宽 640，多面板整体最大宽 1200。宽屏内容组可以在可用区域内居中，组内文字保持起始边对齐。最大宽度用于限制行长和面板规模，不用于按比例放大字体或按钮。

任务列表、设置条目和议程使用连续行与必要分隔，不为每行增加卡片。卡片只用于独立整体：专注复盘、正在执行的关键流程、数据操作确认、图表的整体比较区。任务选择态使用低强度容器色和语义 selected，不依赖新增厚边框造成尺寸跳变。

### 3.2 排版规则

以下数值是本项目建议，单位为逻辑像素，不是 Material 3 的强制字号。行高以“字号/行高”记录；代码用 `height = 行高 / 字号`。沿用系统无衬线和中文 fallback，不引入字体依赖。页面不关闭或统一压制 `TextScaler`。

| 用途 | TextTheme 角色 | 字号/行高 | 字重 | 颜色角色 | 使用条件 |
| --- | --- | --- | --- | --- | --- |
| 页面标题 | headlineLarge | 28/36 | 600 | onSurface | 正常高度；最多两行，避免挤压动作 |
| 低高度页面标题、弹窗标题 | headlineSmall | 22/28 | 600 | onSurface | 可用高度小于 480，或编辑/确认容器 |
| 区域标题 | titleLarge | 20/28 | 600 | onSurface | 同级分组统一使用 |
| 任务主信息、表单组名 | titleMedium | 16/24 | 600 | onSurface | 列表标题、选中任务 |
| 正文、输入内容 | bodyMedium | 16/24 | 400 | onSurface | 表单、说明、备注 |
| 较长操作影响说明 | bodyLarge | 16/26 | 400 | onSurface | 备份、服务器和删除说明；限制行长 |
| 日期、项目、标签、状态 | bodySmall / labelMedium | 14/20 | 400 / 500 | onSurfaceVariant | 必需辅助文字不低于 14 |
| 按钮、筛选标签 | labelLarge | 14/20 | 600 | 由组件前景角色决定 | 不直接指定项目色 |
| 导航标签 | labelMedium | 14/20 | 500，选中 600 | 由导航主题决定 | 显示文字；大字号时允许组件增长 |
| 统计主数字 | displayMedium | 48/56 | 500 | onSurface | 单位用邻近辅助文字，不同单位不混作一组 |
| 专注计时 | displayLarge | 64/76 | 500 | onSurface | tabular figures；低高度使用 48/56 的数字角色 |

未列出的角色仍保留完整 TextTheme，并在主题集中设置；headlineMedium 可使用 24/32，displaySmall 可使用 36/44。中文标题字距为 0；混排正文默认 0；不把拉丁标题负字距应用到中文。

计时、钟点和统计数字使用 `FontFeature.tabularFigures()`，计时容器按最大位数预留宽度。若系统 fallback 的数字特性不同，需通过截图确认宽度稳定；不得通过关闭文字缩放解决。

任务标题默认最多两行并显示省略号；TalkBack 读取完整标题，点击正文打开完整详情或编辑器。大字号下行高度随内容增长。详情和编辑器显示完整项目名、标签和备注，长标签在列表中显示受约束的前两项与“另 N 项”，并以详情/编辑作为完整查看入口；不截断实际保存值。日期与时间可换行，备注不在列表中展开为全文。

### 3.3 颜色、形状和操作层级

固定配色保留 `seedColor = #5664D8`；浅色、深色、跟随系统与用户可选动态色均保留。动态色不可用时仍由固定种子生成。动态方案使用其成套 surface/onSurface；固定方案的现有表面覆盖集中保留并核验，避免动态前景与另一个方案的表面随意混配。

| 语义 | 使用角色 | 限制 |
| --- | --- | --- |
| 页面和普通文本 | surface + onSurface | 不再叠加全页装饰渐变 |
| 同组次级面板 | surfaceContainerLow / surfaceContainer + onSurface | 用于分组整体，不用于每项任务 |
| 元数据 | onSurfaceVariant | 对实际背景至少 4.5:1；不额外降低不透明度 |
| 主要操作 | primary + onPrimary | 一个操作区域一个主要操作 |
| 已选导航、筛选或任务 | primaryContainer + onPrimaryContainer | 同时提供 selected、标记或文字 |
| 次要边界 | outlineVariant；需要识别的控件轮廓用 outline | 重要轮廓核验适用的非文本对比，不用浅装饰线代替控件状态 |
| 已成功保存 | successContainer + onSuccessContainer | 配合完成图标与结果文字；沿用现有扩展 |
| 待处理、权限不足、暂未上传 | warningContainer + onWarningContainer | 只用于有后果的提醒，普通本地模式不持续警告 |
| 校验或操作失败 | errorContainer + onErrorContainer，或 error | 提供原因和重试/修改入口，不只改颜色 |
| 项目自选颜色 | 原色的点/标记 + 正常文字 | 保留数据；不作为正文、按钮或唯一分类标识 |

圆角沿用既有角色：small 10、medium 14、card 18、large 24、overlay 28。连续列表不画每项圆角；点击反馈仍由 Material/InkWell 提供。固定阴影只用于浮层和 FAB，普通信息不以阴影增加视觉优先级。

创建任务和创建时段使用各页 FAB；空列表的创建入口可复用同一个动作，避免同时展示两个 FilledButton。表单保存、开始专注使用 FilledButton；次要授权和条件选择使用 tonal/OutlinedButton；取消、查看说明和提前结束使用 TextButton；删除确认使用有 error 语义的 FilledButton。装饰图标不能成为额外操作入口。

任务完成、打开和更多是独立操作区。当前所有今日任务都有拖拽柄，但已排期任务读模型仍按计划时间排序，拖拽写入 rank 后未必改变位置。本方案只对无当天排期任务显示有效的拖拽和上移/下移；按时间排列的任务不提供无效排序按钮。失败保持原序，成功后列表保持附近滚动位置。

空状态分两类：工作区没有任务时显示“尚无任务”及新建入口；当天没有符合条件的任务时说明“当前日期和筛选下没有任务”，提供调整筛选/日期及日历入口。不能因当天为空就显示首次使用教程或写入演示数据。

宽屏仍优先连续阅读，主列表最大 720；只有无关联任务的计划足够形成独立分组且内容区至少 960 时才将它置于侧面，不为填满窗口复制任务或统计。

实际专注来自 `focusSessions`，不将 `actualSecondsForTask` 的当天总和重复放到每个计划下。只有 `plan_block_id` 等真实关联存在时才说明对应计划；无关联时不猜测归属。活跃记录显示“进行中/已暂停”；其他设备记录不伪造实时秒表。

专注保留准备、历史、规则入口。准备页使用一列连贯步骤，已开始后以任务、状态、计时和控制为核心；规则与说明不与计时争夺首屏。

```text
专注                              权限  设置
[开始 | 历史 | 规则]

未开始：任务选择
        目标 45 分钟
        [25] [45] [60] [90]；15–240 滑杆/数值
        普通 / 守护；实际作用和必要权限
        守护白名单（按项目/收集箱）
        [开始专注]

本机活跃：任务标题（完整内容可查看）
          专注中 / 已暂停 / 目标已到，仍在记录
                    00:32:18
          已用时间 · 目标时间 · 规则
          [完成专注]  [暂停]  提前结束
          暂停后：[继续专注]  完成专注  提前结束
```

默认 45 分钟、快选 25/45/60/90、15–240 范围、按任务预计时长调整均保持现状。没有未完成任务时显示新建任务入口，开始禁用并说明原因；不增加自由专注。守护开始需要两项权限；白名单使用当前项目或收集箱的本机配置，允许为空，空时不增加用户选择的例外应用。缺权限只阻止守护，普通仍可选。

| 专注状态 | 显示和操作 |
| --- | --- |
| 未开始 | 任务、目标、规则、守护条件、一个开始按钮；创建中禁用重复开始 |
| 本机进行中 | 计时可查询；完成为主操作，允许暂停时显示暂停；提前结束为次要操作 |
| 本机暂停 | “已暂停”、已用与剩余不继续变化；继续为主操作 |
| 目标到达 | “目标已到，仍在记录”；剩余为零并显示实际已用，用户完成或提前结束；不自动完成专注或任务 |
| 已结束 | 复盘显示目标/实际/中断与任务；暂不完成任务、再专注、完成任务；提交失败保留复盘 |
| 本机恢复 | 按现有持久化会话及控制标记恢复，暂停仍暂停；界面不声称已验证原生后台服务运行 |
| 其他设备活跃 | 历史中只读；显示记录状态、开始时间和发起设备，禁止本机暂停/恢复/结束/接管；账户工作区开始被阻止 |
| 本地副本含外部活动 | 外部记录仍只读；沿用本地副本可新建本机会话的现有规则，不继承控制标记 |

跨页 dock 只对应 `activeFocusSession` 的本机会话；主信息是任务、状态和可查询的剩余时间，“打开专注”至少 48 dp。暂停/继续与专注页共用 allowPause 和操作忙碌条件；守护不显示可提交的暂停按钮。专注页不再显示 dock。

环形进度只在空间充足时保留，宽度为可用宽度内不超过 276 的值；大字号或低高度时取消环，保留文字计时和进度说明。数字不能为了放进环而缩小系统字号。低高度可将任务/计时与操作按实际空间分区，但阅读顺序始终为任务→状态→计时→控制。

提前结束弹窗先录入实际需要的原因，在保存成功后关闭，失败保留原因和会话。默认守护配置有 `earlyExitMode=countdown`、10 秒，但当前未实施倒计时等待；本方案不增加强制等待，也不写“已强制等待十秒”。该行为差异保留为单独的业务待办，避免在视觉改造中改变结束策略。

日期比较使用成对水平条：计划为空心轮廓/时段标记，实际为实心/计时标记；行内同时显示两项真实数值与单位。每日期只有一个完整语义节点，装饰条排除重复播报。不使用未完成任务个数来填充没有专注数据的图。

全范围计划、实际、完成均为零时显示真实空状态，不绘制零高度假图；只有一类数据为零时保留比较并注明零/无记录。窄屏指标变成可换行的信息行，不挤成三张小卡；宽屏最多三个并列指标，共同对齐基线。28 天仍逐日提供可读取数值，不未经确认改为周聚合或加入同比环比。

```text

  [跟随系统 | 浅色 | 深色]   动态配色开关

  使用情况访问 / 悬浮显示 / 前台计时通知
  白名单入口与当前模式要求
  暂不可用：任务提醒、震动、严格模式

  当前本机工作区；服务器；账户；同步状态
  连接账户 或 退出；已登记设备及撤销入口

  导出本地备份 / 恢复备份
  复制为本地 / 打开保留工作区
  登录时：导出服务器账户
  登录时：删除服务器账户（独立风险区）

  当前版本 / 源码公开说明 / 许可证 / 发布页
```

设置单列按此顺序阅读。足够宽时显示分组索引与一个内容面板，或两个用途清楚且顺序稳定的面板；中等窗口仍用单列，不以两张长卡片并排强塞。分组条目是平面列表，操作状态保持到请求完成；窗口变化不重置 busy。

外观默认跟随系统，动态配色默认开启。开关说明：“支持动态配色时使用系统提供的颜色，不支持时使用默认配色。”保存成功才更新选中状态；失败维持原选择并显示行内重试。任务提醒和震动不使用看似可开的控件；现有通知偏好存储不随移除未实现入口而删除或改格式。

权限说明区分用途：使用情况访问用于识别前台应用；悬浮显示用于守护提醒；通知用于专注前台计时的系统展示。权限状态只能来自平台返回值，不能把偏好开关等同于系统已授权。现有接口未提供可靠状态时显示“检查/申请”，不虚构“已授权”。从系统设置返回刷新已支持的权限；使用情况或悬浮权限拒绝时提供普通模式和系统设置路径，通知拒绝时说明系统通知展示受限并保留本地计时操作。不反复弹权限请求。

同步页面表单最大宽 560，字段顺序：HTTPS 服务器→邮箱→密码→注册所需显示名称→复制/上传选择→连接。地址只接受现有 origin 规则，路径、query、fragment、userinfo 无效；开发 HTTP 例外仅用于既有 debug 配置，不在正式界面推广。邮箱/密码验证维持当前能力，不改写成已实现完整邮箱验证。

“复制当前本地数据并上传”默认不选，旁边说明来源工作区、目标服务器和账户。未选时打开独立目标工作区；已选时保留原工作区并复制到目标；目标已存在则拒绝复制，不合并或覆盖。账户和服务器变化后不复用旧凭据、设备 ID 或同步游标。若有本机活跃专注，连接/切换操作禁用并说明需先结束。

| 操作 | 必须在对应入口说明的实际结果 | 失败/取消处理 |
| --- | --- | --- |
| 退出登录 | 停止同步，保留本机任务、计划、专注及导出能力；服务器撤销请求和本机会话清理分别报告 | 不把撤销未确认写成成功撤销；本地功能继续 |
| 导出本地备份 | 当前工作区、可携带设置（包括本机白名单）、未同步修改；不含密码、令牌、服务器配置、控制所有权或旧游标；系统文件选择器保存 | 用户取消不显示错误；保存失败可重新选择位置 |
| 恢复备份 | v1 格式；最大 50 MiB/100000 文档；校验后事务创建新本地工作区，原工作区保留；停止当前同步、不自动上传 | 校验失败说明版本、字段/引用或文件问题；不切换原工作区 |
| 复制为本地工作区 | 新副本并打开，停止同步、原工作区保留；清除本机会话不等于服务器已撤销此次登录 | 有本机活跃专注时要求先结束；失败保留原工作区 |
| 打开保留工作区 | 离线打开所选本机工作区并停止当前同步；可含旧版、恢复副本、其他账户的本机数据 | 列表无可选项或打开失败时留在设置 |
| 导出服务器账户 | 需要联网及有效会话；不含本机未同步修改，不能代替本地备份 | 会话失效提供重新登录；本地导出仍可用 |
| 删除服务器账户 | 密码和 DELETE；绑定确认时服务器/用户；永久删除服务器账户与数据，保留本机副本 | 请求中保留弹窗、防重复；失败保留输入并允许重试；身份变化则重新确认 |
| 删除本地数据 | 当前无应用内入口，设计中不添加按钮；说明与删除服务器账户相互独立 | 系统清除应用数据属于系统操作，可能删除唯一副本；相关说明要求先保存可恢复备份 |
| 查看发布版本 | 仅打开构建时 RELEASES_URL；未配置显示原因 | 不伪造自动更新检查或维护者在线服务 |

恢复、复制和打开其他工作区保留现有“先结束本机专注”的约束；本地导出不要求结束专注。删除服务器账户不会自动清空本机工作区。风险操作使用具体对象名称与结果，避免泛称“删除数据”。

本机白名单不发送到同步服务器，但当前 `WorkspaceArchive.portableSettings` 包含 `focus_app_whitelists_v1`，用户主动导出的本地备份会携带包名与按项目白名单。备份说明应写清这一点；恢复后的可用应用及权限仍由目标设备决定，备份不授予系统权限或专注控制所有权。

### 4.7 编辑器和弹窗

统一容器：标题与关闭→滚动表单→与字段关联的校验→持久操作错误→SafeArea 内操作栏。紧凑窗口长表单使用接近全高的 Sheet；低高度/键盘场景允许转为全屏 route，但已经打开的容器不因窗口变化重建草稿。中宽窗口使用最大 640 的 Dialog，短确认使用 AlertDialog。

| 编辑器 | 保留的字段、限制及设计处理 |
| --- | --- |
| 任务 | 标题必填 ≤500；备注 ≤50000；收集箱/项目；优先级；可选截止日期和时间；可选预计时长；逗号/顿号拆分去重标签。预计开关默认关闭，启用默认 45 分钟，范围 15–240 |
| 项目 | 名称必填 ≤120；现有八种颜色，默认第一种；可见颜色块 32，点击区至少 48，颜色名和选中状态可读取 |
| 新计划 | 未完成任务或不关联任务；不关联时标题必填；日期、开始时间、15–240 分钟时长；默认任务预计时长或 45 分钟；不将时长控件描述为完整七天编辑能力 |
| 本机白名单 | 项目/收集箱上下文；可启动应用；名称/包名搜索；不进入服务器同步；会随用户主动导出的本地备份携带 |
| 提前结束 | 当前任务、保留实际时间的说明、既有原因输入；失败不丢原因 |
| 删除账户 | 具体服务器和账户、密码、DELETE、永久删除影响；成功后才关闭 |

变更后的返回、关闭、屏障点击和拖拽统一执行“继续编辑/放弃修改”确认；未变更可直接离开。保存中禁用字段与重复提交，阻止意外关闭；完成或失败不依赖动画时长。错误复用 `persistence_errors.dart` 的具体信息，保存失败保留输入和选择，不能自动清空。

提交操作位于键盘以上并可达，表单通过 viewInsets 调整滚动区域。超长字段让表单滚动，按钮允许文字换行和高度增长；不以单独固定高度挤压可编辑内容。

## 5. 响应式结构

导航依据应用窗口尺寸，页面依据扣除导航、系统区域和自身边距后的 `LayoutBuilder` 约束。可用高度另行计算，包括键盘占用；不使用设备型号或屏幕物理大小判断。

| 窗口宽度 | 当前导航 | 建议导航 | 页面结构 |
| --- | --- | --- | --- |
| <600 | NavigationBar | 保留 NavigationBar | 单列；筛选/未排期进入 Sheet；底部 dock 在导航之上 |
| 600–839 | NavigationRail | 保留 80 Rail | 通常单列、最大 720；不因进入 medium 就双栏 |
| 840–1199 | 260 Drawer | 改为 80 Rail | 为内容保留空间；只在实际内容 ≥960 且高度足够时双栏 |
| ≥1200 | 260 Drawer | 保留 260 Drawer | 内容整体最大 1200；符合条件的列表/详情和日历/未排期组合 |

当前四档断点保持不变，1200 以上作为项目的统一更宽窗口档，不要求另增 1600 档。导航改变的是空间使用，不改变目的地、返回关系或业务。

例如 1024 窗口使用 Rail 后，内容扣去 80 和两边 32，为 880，仍单面板；1440 使用 Drawer 后，内容为 1116，可放日历/任务双面板。不能只检查“展开”标签就强行并排。

可用高度小于 480 时：普通 AppBar，辅助说明可折叠查看；导航 Rail 可以滚动到全部目的地；专注取消大环；操作分组允许换行；不将上方摘要、dock 和底栏共同固定成占满窗口的区域。宽度小于 600 且高度很低时，键盘输入阶段临时让底导航避让，退出输入后恢复，不清理页面状态。

SafeArea 与键盘 inset 由共享容器负责，禁止各页重复添加底部系统 padding。全局专注入口使用布局占位而不是遮在列表上；FAB 位于页面内容范围并高于底部入口，最后一行能滚到 FAB 上方。SnackBar 使用统一 ScaffoldMessenger 与实际底部占用，不能被 dock、导航或键盘遮住。

## 6. 状态、无障碍和动效

### 6.1 各类状态的具体处理

| 原因/状态 | 适用位置 | 显示与下一步 |
| --- | --- | --- |
| 初始化中 | 首次打开本机工作区 | 有语义的进度和“正在打开本机工作区”；仅初始化必要范围阻塞 |
| 本地数据库打开失败 | 初始化 | 保留现有专用错误页；具体原因、重试；不显示登录页代替 |
| 工作区为空 | 今日/任务/日历/统计/专注 | 各页按用途说明：创建任务、创建时段、无统计记录、无可选任务；不写入示例 |
| 日期/筛选为空 | 今日/任务/日历 | 显示当前条件，提供清除/换日期；与首次使用区分 |
| 有数据 | 全部主页面 | 按第 4 节层级展示；局部操作不清空整页 |
| 本地写入中 | 完成、排序、编辑、专注、外观 | 对应控件进度、禁用重复；其他不相关本地功能可继续 |
| 保存失败 | 编辑器/完成/专注/设置 | 原值与输入保留；说明不可写、满盘、数据库或请求问题；重试/调整操作 |
| 仅本地 | 全部页面 | 中性状态，无需连接或持续网络警告 |
| 离线、请求失败 | 同步详情与需要联网的操作 | “已保存在本机”＋待同步数量＋最后成功时间（存在时）；重试；本地列表和编辑继续 |
| 会话失效/设备撤销 | 同步详情与设置 | “同步已暂停”＋重新登录；不强制跳走，不删除本机数据 |
| 权限未授予/拒绝 | 守护准备与设置 | 具体权限用途、授权入口、普通模式替代；从系统返回刷新；不声称已授权 |
| 应用目录加载/失败 | 白名单 | 现有加载、读取失败重试、无可选应用、无搜索结果分别保留 |
| 校验错误 | 对应表单字段 | 字段旁原因，提交后将焦点/滚动定位到首个错误；不只弹 Snackbar |
| 备份选择取消 | 系统文件选择返回 | 保留当前工作区；取消不当作失败 |
| 备份格式/引用错误 | 恢复流程 | 显示文件不支持或损坏原因；重新选文件；不切换或覆盖原数据 |
| 不可执行/只读 | 远端专注、守护暂停、忙碌提交 | 可见原因和实际替代入口，不显示能提交的假按钮 |

### 6.2 无障碍

所有触控操作至少 48×48 dp，包括 Checkbox、日期、颜色、Chip、更多按钮和自定义 dock；可见图标通常 20–24，点击区独立满足要求。控件相邻区域不重叠。

正文和必需辅助文字对实际背景至少 4.5:1。本方案同时对主要数字使用这一目标。重要非文字控件和焦点标识按适用规范核验，不能把普通分隔线当作必需控件边界的对比证明。浅色、深色、固定和代表性动态方案分别采样，不根据 seed 推断所有组合通过。

任务行语义分开为完成控件、完整标题/打开、更多；元数据跟随所属任务。项目色点、装饰环、图表重复条和无用途图标排除语义。自定义动作包含用途、选中/禁用和必要数值；禁用原因作为可读文本保留，不只依赖 Tooltip。

计时秒数不设每秒 liveRegion；开始、暂停、恢复、目标到达、结束和保存失败才主动提示。统计每日期播报计划、实际、完成及单位一次。视觉与语义顺序一致，双面板采用明确遍历组，键盘焦点可以到所有操作。

系统字号和显示缩放导致空间不足时，文字换行、容器增长、面板转单列；不限制 TextScaler，不隐藏必要辅助信息。检查 TalkBack 真正的焦点顺序、重复播报、状态提示和自定义组件动作；静态 Semantics 或 widget guideline 通过不等于 TalkBack 验收。

### 6.3 动效和刷新

组件按压、选中、焦点、禁用和加载优先沿用 Material 默认状态。自定义动效仅用于筛选结果、dock 出现/消失、浮层和导航关系，时长集中到现有 AppDurations；不增加持续闪动、弹跳或计时呼吸光。

通过 `MediaQuery.disableAnimationsOf` 尊重减少动态效果；适用时兼顾 accessibleNavigation 的操作时限。自定义切换可立即完成，数据提交和计时从不等待动画。页面变动后焦点和错误可见性优先于运动表达。

保留 AppController 的时间计算和串行专注操作；展示层增加窄订阅/选择器，只在主题、当前页面数据或活跃状态变化时更新对应内容。计时区域和 dock 的时间文字单独刷新；隐藏页面和大列表不因每秒通知重建。此调整不引入新状态管理框架，也不替换本地/原生计时源。
