# Android 手机验收与双机回归

更新日期：2026-10-04。本文供维护者和测试人员记录手机验收进度及安排后续检查。测试结果只适用于对应安装件、设备和操作条件，不替代[正式发布验收](RELEASING.md)。

设备 A 为 Huawei JAD-AL00，B 为 Huawei TAS-AL00，均为 Android 12。2026-10-04 两台均使用无线 ADB，已安装版本代码 7；手机内安装件哈希与测试 APK 一致。APK SHA-256 为 `7ff735e878cb6a43187d6fed3c1e5b52205d23a49be09502e3299a482ea83169`。四份修复实现文件与其构建目录一致，完整来源核对记录保存在本地测试目录。

## 双机检查结果

| 检查 | 实际结果及限制 |
| --- | --- |
| 默认登录不上传 | 两台默认不选择复制上传，服务器工作区没有原本地测试任务；原工作区保留。单独验证了明确选择复制上传 |
| 默认专注规则 | 升级恢复旧拒绝并采用服务器规则；新账户首次登录和一次受控登录竞争中，各机两条规则、无拒绝和待发送操作。不能由一次竞争覆盖所有请求顺序 |
| 共享业务记录 | 任务、项目、计划、完成状态及专注历史完成双向交换。部分准备与修改通过生产控制器调用，不计为所有按钮及编辑器验收 |
| 标签、排序和外观 | 共享标题更新后，各机保留自己的任务标签和排序值；服务器不含这两项本机字段。B 的主题和动态色偏好冷启动保留，A 未受影响；未验证系统实际提供动态配色 |
| 离线合并和删除下载 | 模拟 HTTPS 入口中断后按指定顺序上传，不同字段合并，同字段结果符合服务器接收顺序；电脑提交墓碑后两机下载删除。未验收手机删除入口和任意离线竞态 |
| 专注所有权和交接 | 其他设备的活跃专注保持只读，不启动本机计时服务；A 完成后 B 可开始。两机受控离线竞争时，一个会话被接受，另一个收到重叠拒绝并保留本地记录 |
| 401 后真实刷新恢复 | 两台分别只使测试 API 的访问令牌无效，保留有效持久会话，再执行真实服务器强制刷新。认证暂停解除、周期定时器恢复、任务自动上传且 ID 不重复；此项是受控认证回归 |
| 手动重试后的周期下载 | A 恢复有效令牌后通过页面点击“立即同步”；随后不编辑 A、不切换其前后台、不重绑或调用同步。B 修改任务后，A 约 30 秒后通过周期同步下载，成功同步时间推进 |
| 物理 Wi-Fi 恢复 | 用户关闭 A 的 Wi-Fi 并返回 Pactick；应用自身网络探测失败后调用生产任务保存逻辑。恢复前服务器没有该任务，恢复后在调试连接重新附加前已自动上传，B 自动下载，服务器只有一个 ID。未计为断网期间物理点击保存按钮验收 |
| 锁屏、自然到期与结束 | 用户确认锁屏后观察 919.72 秒，原生服务保留同一未暂停会话，跨过原令牌到期及 900 秒目标。恢复入口并打开应用后，会话已续期、队列自动上传并互相下载，无同步拒绝。页面目标到时仍记录，人工结束后两机与服务器实际时长均为 1181 秒，服务停止 |
| 退出和清理 | 原工作区任务 ID、数量和外观保持；本地副本保留。临时账户删除后数据库按精确 UUID 查询为零，本轮调试附加、转发和临时入口已清理；测试后端保持运行 |

锁屏组合中临时中断的是测试 HTTPS 入口，手机 Wi-Fi 保持连接。原令牌到期时间落在用户确认的锁屏区间，恢复后的会话到期时间推进；没有要求自然场景出现 401，也不能仅由到期时间判断刷新必由解锁触发。锁屏时长依据用户确认及电脑时间，不代表逐秒读取了系统锁屏状态。此项不证明锁屏期间持续联网自动同步。

## 后续验收与完成条件

以下项目仍需执行。最终候选包含修复后，应重新记录其源码、APK 哈希和证书，不能沿用独立 LAN 包的签名或制品结论。

- 正式包首次安装与覆盖更新：保持正式包名及签名，逐条记录实际旧版到新版路径；核对任务、计划、历史、未同步修改及显式保存的外观。旧 `com.example.planfocus` 的独立安装和备份迁移另测，不卸载唯一数据副本。
- 备份、恢复与文件选择器：使用合成工作区导出并在新工作区恢复，核对记录及未同步内容，确认原工作区保留且没有自动上传；取消选择和失败不能算通过。
- 系统行为：分别验证通知拒绝、权限变化、守护白名单拦截、强制停止与系统回收、设备重启、TalkBack、预测性返回、横屏、系统字号和更多 Android 版本。用户处理权限提示不代表这些分支已验收。
- 持续联网的锁屏同步：保持测试服务可达，不读取或唤醒锁屏界面，在另一设备编辑记录，核对上传、下载与令牌自动续期实际发生的时间；与解锁后恢复单独记录。
- 完整手机操作：对当前 UI 提供的按钮和表单逐项验收。缺少完整入口的删除、计划修改等能力记录为当前不支持，不用电脑 API 或控制器调用替代 UI 完成条件。
- 第二服务器与公网服务：两个独立服务器返回相同用户 ID 时分别验证数据、凭据和游标隔离；公网 HTTPS、证书签发续期和 WSS 与局域网 REST 同步分开验收。

## 受限读取下的测试操作

当操作者限定只读取 Pactick 时，ADB 只用于指定 Pactick 包及其 APK、包内文件、本进程日志和应用调试服务。界面状态从 Pactick 自身 Flutter 树读取；不得先采集整屏层级或截图，再以过滤非 Pactick 节点替代限定读取。系统安装、权限、键盘、文件选择器及锁屏操作交由操作者处理，并单独记录其确认和实际验证范围。

2026-10-04 的早期辅助代码曾先读整屏再过滤，不符合该限制；后续已停止整屏采集并移除相应可执行方法，改为仅读 Pactick 自身状态。早期截图和 XML 不作为严格限定读取的合规证明，原始失败及修正记录保留。

两台均为无线 ADB 时，物理 Wi-Fi 切换由操作者手动关闭和恢复。关闭 Wi-Fi 会使无线调试断开，不能依赖同一连接发送恢复命令。恢复后先从服务器核对任务是否自动上传，再重新附加调试；重新连接调试不计为任务保存或同步按钮操作。

测试只使用可丢弃账户和合成数据，先记录原工作区及外观。结束专注后退出测试账户、恢复原工作区、核对数据，最后删除临时账户并清理本轮辅助。只删除归属于本轮的账号、转发和进程，保留数据库服务及其他部署。临时 LAN 入口已停止，后续手机测试需要重新提供可达且证书受信任的入口。
