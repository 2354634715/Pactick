# Pactick Android GUI 实施与验证记录

日期：2026-10-02。适用客户端：`0.2.0-preview.1+3`。设计依据为已确认的 [Android GUI 方案](ANDROID_GUI_DESIGN.md)。本文记录当前工作目录的实施结果及验证范围，不代表正式发布或 Android 真机验收。

## 界面与操作变化

| 页面或流程 | 当前结果及使用方式 |
| --- | --- |
| 今日 | 日期与当天摘要在前，待办/已完成和当天排期筛选随后，任务按有排期、无排期分组。未关联任务的计划单独展示；不再重复突出第一项任务。无排期任务可以拖动，也可以从更多菜单上移、下移。 |
| 任务 | 保留收集箱、项目、标签、已完成和搜索。任务采用连续列表；完成框、查看正文和更多菜单是独立目标。标题最多两行，辅助信息最多三行，点击正文可以查看完整标题、备注和标签，再明确选择编辑。完成操作提供撤销；撤销按当前工作区和最新任务恢复完成状态，避免覆盖其他字段。 |
| 日历 | 保留日、周、月视图。周视图仍是日期概览加选中日议程。截止、计划、实际专注分别使用文字和形状标识；全天入口可查看 0–23 时，跨日记录按当前日的可见范围展示，但不改持久化记录。实际专注按独立记录显示，不随关联计划重复显示。重叠有文字说明，长标题可打开完整只读详情。未排期任务可点按钮排期，也可拖动；保存失败保留原排期意图并提供重试。 |
| 专注准备 | 必须选择未完成任务；没有任务时提供新建入口。保留 25、45、60、90 分钟快捷选择及 15–240 分钟范围。守护模式说明使用情况访问、悬浮窗和白名单用途；权限操作失败显示原因和普通专注替代说明。严格模式不显示成已可用能力。 |
| 专注进行与恢复 | 任务标题最多两行，可点击查看完整名称。计时使用等宽数字特性；大字号或低高度时取消大环。目标到达后显示“目标已到，仍在记录”和已专注时间，不自动结束。暂停时继续成为主要按钮；允许暂停条件与跨页入口共用规则。保存期间禁用重复操作，失败保留当前上下文。 |
| 专注结束与历史 | 完成专注先保存专注记录，再提供复盘和任务后续选择；不会自动完成任务。提前结束说明保存实际时长且不完成任务。失败留在原对话框并保留输入。其他设备的活跃记录只读，不增加本机控制或实时远程倒计时。 |
| 统计 | 明确近 7 天或近 4 周的起止日期、当前工作区、分钟单位和计算口径。每日计划与实际使用相同长度基准，并提供文字数值。计划为零时不计算比例；全部指标为零时显示真实空状态。实际专注取已保存值，仍按现有开始日期归属和状态汇总规则计算。 |
| 设置 | 外观、专注权限、可选同步、本机数据及关于按用途连续分组。外观保存、权限请求、设备操作和数据操作有忙碌及失败反馈。尚未实现的提醒、震动和严格模式使用说明文字，不提供可提交的假开关。 |
| 任务、项目、计划与白名单编辑 | 共享编辑容器统一关闭、遮罩、下拉关闭和返回处理。存在修改时确认是否放弃；保存期间禁用关闭与重复提交。保存失败保留输入。窄窗使用底部编辑面板，较宽窗口居中；字段可滚动，提交操作避让系统区域和键盘。 |
| 同步登录、备份与删除 | 登录仍用于可选同步，复制并上传默认不选；连接与工作区切换继续调用原有隔离逻辑。备份、恢复、复制、打开本机工作区、服务器导出、退出及删除分别说明实际影响。服务器删除必须输入密码和确认文本；请求进行中禁止重复提交，失败保留输入并留在确认页。 |

界面继续调用现有 `AppController` 和 `SessionController`。存储、同步、账户和专注所有权规则未替换；新安装仍不写入业务示例。截图中的项目、任务、计划仅存在于 `MemoryDocumentStore` 测试实例，不进入正式工作区。

## 共享布局和视觉规则

间距仍使用 4、8、12、16、24、32、48 逻辑像素。页面按实际内容约束采用 16、24、32 边距；主内容最大宽度为 1200，单列页面为 720，阅读区域为 680，表单为 560，编辑容器为 640。任务正文的主要对齐线位于 48 宽完成目标与 8 间距之后；区域标题、表单标签和列表内容通过共享容器及组件对齐。

`TextTheme` 集中设置页面标题、区域标题、任务正文、辅助文字、操作标签与数字角色。字号、字重和行高见设计方案及 `app_theme.dart`。所有角色字距为 0，取消标题的负字距；产品没有新增字体依赖。正文和必要辅助信息分别使用 16 和 14 字号，AppBar 标题采用实际系统 `TextScaler` 并调整高度。计时数字使用 tabular figures，宽度不足时通过数字与单位换行适配，不关闭系统文字缩放。

浅色、深色、跟随系统和可选动态取色入口保留。固定配色使用原有蓝紫 seed；动态方案直接使用其配对颜色角色，不再以固定 surface 替换动态背景。正文、辅助信息、容器、选中状态和错误使用 `ColorScheme` 语义角色。项目自选颜色只用于色点，项目名仍使用正常文字颜色。任务与设置使用连续信息布局；卡片保留用于本次专注配置等整体交互单元。

共享主题保留 Material 按压、焦点、选中和禁用状态，设置图标按钮最小 48 触控目标。日期目标与自定义入口补充语义；装饰环、色点及图表重复条排除重复播报。计时数字可被读取，但不设为逐秒 live region；目标到达和保存错误使用状态提示。自定义编辑过渡与 dock 动效尊重 `disableAnimations`，不依赖动画完成计时或保存。

| 实际窗口宽度 | 导航 | 内容结构 |
| --- | --- | --- |
| <600 | NavigationBar | 单列；任务详情与未排期任务使用浮层。低高度输入时暂时避让底导航、FAB 和专注入口，输入结束后恢复。 |
| 600–839 | 80 宽 NavigationRail | 通常保持单列，不因进入中等档自动并排。 |
| 840–1199 | 80 宽 NavigationRail | 由实际剩余内容宽度与高度判断，避免 260 宽抽屉挤占主要内容。 |
| ≥1200 | 260 宽 NavigationDrawer | 满足内部 960 宽及高度条件时，任务使用列表与详情，日历使用议程与未排期面板；内容整体限制最大宽度。 |

主页面宿主的组件路径保持稳定。导航断点改变时保留筛选、搜索、日期、选择与滚动；设置作为独立 route 打开，返回后继续原页面。切换目的地先退出隐藏输入焦点，保留文本。专注入口通过布局占位，页面为 FAB 提供可滚动尾部空间。Android Manifest 启用预测性返回回调，主题使用 Android 预测性返回过渡；实际手势效果仍需设备检查。

`AppDataBoundary` 是展示订阅层，过滤纯计时通知；业务列表、设置、权限、同步和工作区变化仍通知页面。`FocusClock` 单独监听计时更新，避免每秒重新构建应用主题和整个页面。该处理没有修改控制器、仓库或平台网关。

## 未验证事项与保留限制

`adb devices -l` 未发现已连接设备，本次没有执行 Android 真机或模拟器验收。以下项目仍需 Android 环境：TalkBack 实际播报和焦点顺序、系统键盘及显示缩放、预测性返回手势、真实权限拒绝和设置返回、系统动态颜色、后台与恢复行为、启动器遮罩和主题图标。Widget 测试中的返回、2 倍字号、窗口变化及 240 高键盘 inset 不能替代这些检查。

本次没有连接真实服务器测试登录、上传、会话过期、退出、备份文件选择器及删除账号；现有控制器与接口测试只证明其自动化覆盖范围。正式签名、安装升级、发布包大小优化和生产服务器验收未进行。

自由专注、严格模式、提醒调度、震动、重复规则编辑、独立标签管理、任务删除、清空本机数据、已有计划完整编辑/删除仍属于原有未实现能力。统计的跨日归属与状态汇总继续使用原规则；改造没有引入新的统计算法、持久化格式或同步协议。
