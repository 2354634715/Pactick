服务操作

首次使用先选择运行方式和端口，再部署。停止服务保留数据库及配置。

数据库迁移

更新发行包前先备份。迁移会停止 API，可能提交数据库结构变更；失败后请检查日志及备份，再重试。程序不自动恢复旧数据库。

连接安卓客户端

在安卓客户端的同步设置中填写可访问的服务器地址。默认回环监听仅供本机使用；其他设备连接需在运行配置中启用局域网监听，并自行配置 HTTPS 代理和防火墙。

ACCOUNT ACCESS

创建服务器账户

填写邮箱后即可创建账户。密码留空时生成随机密码；账户创建不开放公开注册。

账户已创建

请将密码保存到密码管理器。刷新或关闭页面后，程序不会再次显示生成的密码。

RUNTIME SETTINGS

运行配置

配置保存在此电脑的数据目录，服务运行期间不能修改。已部署实例不能直接切换运行方式或数据库。

保存后不回显已有连接地址。保持空白会保留原值。使用为 Pactick 单独创建的数据库。

所有接口监听会允许其他设备访问 API。请按网络范围配置防火墙；公网使用须配置 HTTPS/WSS 代理。管理界面仍只监听本机。

Docker 模式需要 Docker Engine/Desktop 与 Compose v2，首次部署需联网下载容器镜像。
