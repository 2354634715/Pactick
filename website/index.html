05 / 常见问题

再多了解一点。

使用前需要注册账号吗？+

本地使用不需要账号，也不需要部署服务器。只有选择同步时，才需要连接自己的服务器并登录相应账户。

有 Windows、iOS 或 Web 客户端吗？+

本轮提供 Android 客户端。Windows 与 Linux 下载项是同步服务端管理程序；目前未提供这些平台的桌面客户端、iOS 客户端或 Web 客户端。

这是开源软件吗？+

Pactick 采用 Source Available 许可，源码可查看，但不是 OSI 开源许可。使用、修改和分发须遵守项目许可证；商业用途的具体条件见许可 FAQ。

安装或升级前，需要备份吗？+

建议先导出本地备份并妥善保管。普通任务等备份内容为明文，私密箱部分保持密文；私密备份需保留导出时的密码。恢复和升级限制请参阅发布说明。旧包名应用不会通过覆盖安装自动迁移，按安装与迁移说明操作。

可以切换语言或启用专注桌面吗？+

设置支持跟随系统、简体中文与 English。专注桌面默认关闭，开启后展示系统及白名单应用；它不替换 Android 默认桌面，也不提供系统应用锁。

系统日历和私密内容如何处理？+

系统日历连接默认关闭，确认授权后交换普通计划，可能由日历账户或 Pactick 同步到相应服务器。私密箱使用独立密码和本机密文存储，不参与账户或系统日历同步；可导出独立密文备份。
