# 官网本地预览与维护

[English](GUIDE.en.md)

`website/` 是独立的静态官网，介绍 Android 客户端、本地使用与可选同步，并提供 GitHub、发行附件和项目文档入口。它不连接应用工作区或同步 API，也不替代服务端管理界面。

## 在本机预览

需要 Node.js 18 或以上。在项目根目录运行：

```powershell
node website/server.mjs
```

打开 <http://127.0.0.1:4187>。服务仅监听本机回环地址，按 `Ctrl+C` 停止。不需要安装 npm 依赖或执行构建。

端口被占用时，命令会退出并报告原因。可指定其他端口：

```powershell
node website/server.mjs 4188
```

也可直接用浏览器打开 `website/index.html` 或 `website/index.en.html`。两个页面的语言链接使用普通链接，不依赖 JavaScript。本地 HTTP 预览便于检查资源响应和安全策略，应作为修改后的主要检查方式。

## 文件与行为

| 文件 | 用途 |
| --- | --- |
| `index.html`、`index.en.html` | 中文和英语页面，包含相同的功能范围、版本、下载直链与对应语言的文档链接 |
| `styles.css` | 共享色彩、系统字体、响应式布局及交互状态 |
| `app.js` | 切换今日、日历和专注三个功能示意；支持方向键、Home 和 End |
| `assets/pactick-icon.png` | 复制自 `client/assets/branding/pactick_icon.png` 的现有项目图标 |
| `server.mjs` | 本地预览；白名单仅提供两个 HTML、共享 CSS、共享 JavaScript 和项目图标，不提供其他仓库、配置或文档文件 |

页面采用暖灰纸色、深棕文字、宋体标题、橙红主操作和蓝绿色链接。正文及操作控件使用系统无衬线字体。布局依据项目既有网页设计说明；客户端与宣传短片保留各自的视觉体系。

示意面板只显示固定示例数据，不是应用截图，也不能创建任务或启动计时。禁用 JavaScript 后，页面保留今日示意；下载、锚点、文档链接与原生折叠说明仍可使用。

页面不包含统计脚本、外部字体、CDN 或后台请求。访问 GitHub 链接与下载附件需要网络；页面不会自动选择或下载文件。

## 更新下载版本

页面固定目标为 `v0.3.0-preview.3`，下载链接采用约定的制品名。发布前可以先固定本页源码，上传完成后逐一核对目标；页面中的链接本身不证明附件已经可下载。

| 项目 | 页面采用的版本 |
| --- | --- |
| Android 客户端 | `v0.3.0-preview.3`，构建号 8，Android 8.0 / API 26 及以上 |
| APK | `pactick-0.3.0-preview.3-build8-release.apk`；页面仅显示“通用 APK”，实际大小与 SHA-256 以最终 Release 附件和校验文件为准 |
| 本版附件 | Android APK、完整源码和 `SHA256SUMS.txt`；不承诺新版服务端二进制 |
| Windows/Linux 旧服务端 | `v0.3.0-preview.1`，x86-64；同步工作区的终态专注首次关联任务须按 preview.3 源码升级服务端 |

版本固定在两份 HTML 中，不通过 GitHub API 自动更新。旧服务端下载仍指向 [preview.1](https://github.com/2354634715/Pactick/releases/tag/v0.3.0-preview.1)，并在下载旁说明版本与升级要求。`releases/latest` 不适合代替已核对的预发布附件地址。本页不重复保存 APK 哈希或大小；“见 SHA256SUMS.txt”直接链接本版校验文件，用户按最终附件核对。这样可以在正式签名构建前固定源码，无需因构建产生新的哈希再修改页面。

维护者按以下顺序完成本次发布链接：

1. 发布后从 Release 核对实际附件地址、平台、架构、大小与 `SHA256SUMS.txt`。页面不复制哈希或大小。若制品名需要变化，在固定下一份候选源码之前同步更新链接；不能将发布页当作 APK 文件直链。
2. 同步核对 `index.html` 与 `index.en.html` 中首屏和下载区的 APK 地址、版本、构建号及校验文件链接。每个页面的两个 APK 入口带有 `data-download="android"`，应指向同一文件。
3. 核对服务端附件是否有更新，保留其独立的版本说明；Windows/Linux 服务端不能标为桌面客户端。
4. 发布后核对 preview.3 标签下的使用指南、许可、迁移和服务端升级文档及其锚点；英语页面使用对应的英语文档。后续版本更改时同步维护本指南两种语言。
5. 检查中英语言往返、下载入口、所有示意面板、折叠说明、键盘操作及窄屏换行。禁用 JavaScript 后仍须能切换语言、下载、查看文档与打开折叠说明；示意默认保留今日。

GitHub 附件被删除、改名或改变访问权限后，固定直链可能失效。页面不绕过 GitHub 或浏览器的下载限制，也不自动验证下载文件。用户通过本版校验文件核对实际下载的 APK；未通过校验时不得仅凭文件名确认安装包。

## 交付范围

官网源码和本地预览命令随本版源码归档提供；本轮不注册站点或部署到实际服务器。

静态站点的运行资源为 `index.html`、`index.en.html`、`styles.css`、`app.js` 和 `assets/`。本地预览服务器、本指南和本地检查记录不属于站点运行资源。当前没有部署站点；若以后部署，缓存、HTTPS 和响应头须按托管环境另行配置。`server.mjs` 中的 CSP 仅对其本地 HTTP 响应生效。服务器仅接受 GET/HEAD，其他方法返回 405；白名单外路径返回 404，不能改为整个仓库的静态目录服务。
