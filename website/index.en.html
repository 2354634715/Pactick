Need your own sync server?+

The Windows/Linux packages are server managers for self-hosted sync. They are not required for local Android use.

The server packages below are v0.3.0-preview.1. This release has no new server binaries. An initial Docker deployment requires Docker and Compose, plus a network connection to download images.

To link an ended free-focus session in a synchronized workspace, upgrade the server using preview.3 source. The older packages below do not include that support. Back up the database before upgrading.

05 / COMMON QUESTIONS

A few more details.

Do I need an account?+

Local use requires neither an account nor a server. Connect your own server and sign in only when you choose synchronization.

Are there Windows, iOS, or web clients?+

This release provides an Android client. Windows and Linux downloads are sync server managers. Desktop, iOS, and web clients are not currently provided.

Is this open-source software?+

Pactick uses a Source Available license, not an OSI-approved open-source license. Use, modification, and distribution must follow the project license. For commercial-use conditions, read the license FAQ.

Should I back up before installing or updating?+

Export and retain a local backup first. Ordinary task content is plaintext; vault content stays encrypted. Keep the password used when exporting a private backup. Check release notes for recovery and upgrade limitations. The old package name does not migrate through an in-place update; follow the installation and migration guide.

Can I change languages or use a focus desktop?+

Settings supports the system language, Simplified Chinese, and English. The optional focus desktop is off by default and shows system and allowed apps. It does not replace Android's launcher or provide a system app lock.

What about system calendars and private content?+

System calendar integration is off by default. After you grant access and confirm, ordinary plans can be exchanged and synchronized by the calendar account or Pactick. The private vault uses a separate password and local encrypted storage, stays out of both sync paths, and supports independent encrypted backups.
